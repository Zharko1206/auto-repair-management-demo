# 基于 SpringBoot 的小型汽修门店业务管理系统的设计与实现

项目主题：小型汽修门店业务管理系统（计算机毕业设计演示）。

## 技术栈

- 当前演示：Vue 3、Python、SQLite。
- 选题方案：Vue 3、Spring Boot、SQLite（部分技术尚未接入）。

## 项目功能

支持维修工单查询、筛选、维护和 CSV 导出，并记录操作日志。

完整方案规划包括：车辆档案、接车开单、维修派工、配件库存、结算收款、技师提成、客户回访、经营报表。部分功能尚待开发。

## 运行方式

在项目目录运行 `python3 backend/server.py`，然后访问 http://127.0.0.1:8000。
